## 适用场景
用户问 NestSpace 自身设置在哪里、怎么改，或想了解当前该去哪个页面。

## 步骤
1. 先判断设置属于哪一类：语言、模型、系统提示词、权限、悬浮球、浏览器代理、外部 MCP、坐标模拟、桌面/壁纸、定时任务。
2. 用文字给出准确入口，例如：
   - 模型：空间设置 → 模型设置
   - 系统提示词：空间设置 → 系统提示词
   - 权限：空间设置 → 权限级别
   - 悬浮球：空间设置 → 悬浮球
   - 浏览器代理：空间设置 → 浏览器代理
   - 外部 MCP：空间设置 → MCP 工具
   - 坐标模拟：空间设置 → 坐标模拟
3. 如果用户要求你直接代改，先说明：本地助手的工具列表里没有 `nestspace_*` 设置工具，这些工具只在远程 MCP 控制服务中提供；你不能直接改宿主设置。
4. 请用户在对应页面操作；用户操作后，只有界面或工具结果明确确认时才说已生效。
5. 不要读取、复述或猜测 API Key、Token、密码。

## 容易出错的地方
- 不要声称已经改了设置，除非确实有工具结果或用户确认。
- 不要把“外部 MCP 工具”和 NestSpace 对外的 MCP 控制服务混淆。
- 不要建议用户放宽权限、开启局域网监听或删除配置来绕过问题。
- 语言切换后界面文案会变，但用户数据不变。

## 怎样算完成
用户知道具体入口和下一步；没有编造修改结果。无法代改时明确说明原因。

## 什么时候停下交给用户
涉及密钥、权限放宽、局域网暴露、删除配置或付费模型时，先说明影响并让用户自己操作。
