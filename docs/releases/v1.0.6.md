# NestSpace v1.0.6

这个版本集中完善了模型配置、AI 助手操作应用、内置浏览器下载和容器兼容性，同时重新整理了空间设置、平板布局与发布文档。

## 重点更新

- AI 助手会区分“直接打开应用”和“在后台获取信息”：前者进入正常应用界面，后者只在 AI 任务期间使用无头镜像小窗。
- 新增模型配置引导、Claude/OpenAI 预设和常见厂家选择，首次使用可以更快完成模型配置。
- 浏览器下载、网页跳转和 AI 获取应用信息统一留在 NestSpace 内，不再交给系统浏览器。
- 增强运行时热加载和多进程隔离兼容，修复部分加固应用在免责声明后无法进入首页的问题。

## 新增

- 支持导入宿主设备上已经安装的应用，并创建独立的虚拟空间副本。
- 新增 Claude 与 OpenAI 协议预设、厂家胶囊选择、Base URL 和默认模型自动填充。
- API Key 支持切换明文显示；模型地址会自动识别并补齐 `v1/messages`。
- 新增模型配置引导页。首次运行可以选择配置模型，也可以先跳过。
- AI 助手未配置模型时显示“去配置”，配置完成后显示欢迎界面。
- AI 助手历史改为独立列表，可选择恢复历史对话或删除记录。
- 悬浮球对话界面改为精简的语音助手形态，只保留当前对话，不显示完整历史。
- 离线语音模型支持在下载过程中切换保存路径。
- 内置浏览器新增下载菜单、下载进度卡片和下载列表删除功能。
- 新增品牌化启动动画和容器加载动画，保留原有头像标识。
- 设置页重新分类，并增加 AI 助手、模型、社交等常用入口。
- “关于”页面新增交流群入口、交流群二维码和二维码保存到本地功能。
- README 补充交流群入口。
- 新增版本发布说明模板、发布文档和 GitHub Release 自动发布流程。
- 新增自动化测试覆盖模型配置、语音文本、容器原生库和 AI 操作展示规则。

## 修复

- 修复模型设置为空时仍自动出现 Claude 配置的问题；现在默认保持为空。
- 修复模型为空时缺少明显添加入口的问题。
- 修复模型连接失败的提示占用页面顶部的问题，统一改为 Toast。
- 修复中文语音识别结果出现大量多余空格的问题。
- 修复打开下载页、网页重定向或 AI 获取应用信息时可能跳出内置浏览器的问题。
- 修复部分目标应用再次打开白屏、返回直接回到平板桌面、关闭后仍有声音以及误用系统 PiP 的问题。
- 修复无头任务启动时短暂全屏显示应用、随后缩回容器的问题。
- 修复 `ui_wait_for` 未传文字时错误返回成功的问题。
- 修复系统空间通过启动指令误打开浏览器包的问题。
- 修复加固应用的运行时隐藏 DEX 未加载，导致同意免责声明后出现 `NoClassDefFoundError` 的问题。
- 修复应用启动推送子进程时，进程池错误结束当前前台容器的问题。
- 修复多个容器子进程重复创建 AI 语音悬浮窗，出现多个话筒入口的问题。
- 修复部分应用返回后重新进入自身、启动 Activity 失效或从通知重新打开的问题。
- 修复平板返回键、容器退出和部分应用生命周期行为异常的问题。

## 优化

- 精简 AI 助手页面和模型配置页面文案，减少重复说明和无关提示。
- 模型配置、上下文长度、最大输出和最大工具轮次输入更紧凑。
- AI 助手设置、模型设置和历史记录都可以从更直接的入口进入。
- 优化平板布局，底部快捷入口保持底部排列，不再增加主页侧边栏。
- 优化应用管理、空间设置和常用入口分类，不常用设置移入次级页面。
- 优化容器加载动画、镜像窗口和前后台切换，减少闪屏与全屏跳变。
- 无头小窗作为 AI 助手组件使用，只在 AI 助手界面可见时显示。
- 网络线路测试会执行三次并取最优结果，减少偶发波动。
- 手机与平板通用应用兼容逻辑优先按 APK 和组件能力处理，减少针对单个软件的硬编码。
- 交流群二维码保持原始 `702×705` 尺寸，通过黑白 PNG 优化将体积从约 369 KB 降至约 7 KB。
- 更新 README、使用文档、架构说明、设置说明、浏览器说明和故障排查文档。

## 升级注意

- 从 `v1.0.5` 升级可以直接覆盖安装正式签名 APK，原有空间和应用数据会保留。
- Debug APK 与正式 APK 签名不同。已经安装 Debug 版时，安装正式版前需要先卸载。
- 系统 PiP 能力保持开放，但 AI 助手执行无头任务时不会额外进入系统 PiP。

## 安装包

- `NestSpace-v1.0.6-arm64.apk`：ARM64 真机和带 ARM 转译的模拟器。
- `NestSpace-v1.0.6-x86_64.apk`：x86_64 PC 和模拟器。
- `NestSpace-v1.0.6-universal.apk`：不确定 ABI 或需要通用包时使用。
