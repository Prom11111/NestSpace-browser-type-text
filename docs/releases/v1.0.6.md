# NestSpace v1.0.6

这个版本重点完善 AI 助手操作虚拟应用时的显示方式、内置浏览器安全性和中文语音输入，同时更新了模型设置和空间管理体验。

## 重点更新

- AI 助手会区分“打开或操作应用”和“获取信息”：前者使用全屏应用，后者使用方形无头小窗。
- 新增模型配置引导，没有模型时可以进入设置页完成配置。
- 内置浏览器接管网页弹窗、网页回退链接和下载页，不再跳到系统浏览器。
- 中文语音识别会自动整理词间空格，避免出现“打 开 抖 音”这类文本。

## 新增

- 支持从宿主导入已经安装的应用，并安装为独立的虚拟空间副本。
- 下载文件支持在浏览器内查看进度，并可从下载列表删除。
- AI 对话中支持显示下载进度和可展开的工具执行记录。
- 新增模型配置页、模型预设和兼容接口配置。
- 支持为离线语音模型选择下载路径。
- 启动容器时增加品牌化加载动画和动态状态文案。
- README 新增 Telegram 交流链接和微信群二维码。
- “关于”页面新增 Telegram、微信群二维码和二维码保存按钮。
- 使用文档按当前应用的设置分类、应用导入、AI 助手和浏览器行为全面更新。

## 修复

- 修复部分页面点击“下载 App”时打开系统 Chrome 的问题。
- 修复虚拟应用通过 `intent://` 网页回退地址跳出 NestSpace 的问题。
- 修复系统空间通过 `space_launch` 启动浏览器包的问题。
- 修复抖音第二次打开白屏，以及双击返回直接回到平板桌面的问题。
- 修复 `ui_wait_for` 不传文字时错误返回成功的问题。
- 修复模型连接失败提示占用页面顶部的问题，现改为 Toast。
- 修复中文语音识别结果包含大量多余空格的问题。

## 优化

- “打开抖音”“打开抖音搜索”“获取抖音信息”等指令会按最终目标选择显示方式。
- 其他虚拟应用使用相同的全屏与无头小窗判断规则。
- 无头任务启动时保持 AI 助手页面稳定，不再闪现全屏容器。
- 系统 PiP 能力保持开放，但 AI 无头任务期间不会额外进入系统 PiP。
- 镜像小窗改为方形直角，并支持关闭时同时停止应用进程。
- 模型连接成功、失败、保存和删除等临时提示统一使用 Toast。
- 优化平板布局、设置分类、应用管理和 AI 助手界面文案。
- 移除文档中的外部容器产品与商业方案比较，只保留 NestSpace 自身说明。

## 升级注意

- Debug 安装包可以直接覆盖安装，但调试版与正式版签名不同。
- 升级正式版时仍应使用 `v1.0.6` 发布页中的签名 APK，避免覆盖安装失败。

## 安装包

- `NestSpace-v1.0.6-arm64.apk`：ARM64 真机与带 ARM 转译的模拟器。
- `NestSpace-v1.0.6-x86_64.apk`：x86_64 PC / 模拟器。
- `NestSpace-v1.0.6-universal.apk`：不确定 ABI 或需要通用包时使用。
